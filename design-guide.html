Dark Mode

The theme system uses CSS custom properties with three layers of specificity:

  1. :root — light mode defaults
  2. @media (prefers-color-scheme: dark) / :root:not([data-theme="light"]) — auto dark
  3. :root[data-theme="dark"] — forced dark override

Toggle by setting data-theme on <html> and persisting to localStorage. All components use var(--token) references so they adapt automatically.

Theme toggle script
function toggleTheme() {
  const html = document.documentElement;
  const current = html.getAttribute('data-theme');
  const next = current === 'dark' ? 'light' : 'dark';
  html.setAttribute('data-theme', next);
  localStorage.setItem('theme', next);
}
